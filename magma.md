## Note on Benchmark Data Availability

To comply with the Open Science requirements, we have made our system prototype publicly available in this repository.

However, the benchmark data used in our experiments is relatively large and exceeds the practical size limits for this repository. Therefore, we host the full benchmark dataset in a separate repository.

The benchmark data and experiment setup can be accessed here:
https://anonymous.4open.science/r/magma-2823

This prototype repository focuses on the implementation and tooling, while the benchmark repository contains all datasets necessary to reproduce the experimental results reported in the paper.

Thank you for your understanding.
